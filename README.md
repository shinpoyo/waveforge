# WaveForge Web DAW

ブラウザで動く、波形オーディオのマルチトラック編集ツール（個人制作）。

## Web版（インストール不要）

https://shinpoyo.com/waveforge/

- 音声ファイルを読み込んで、カット・移動・フェード・音量調整などの編集ができます
- 編集できるトラックは8本まで（9本目以降はロック状態で保持され、再生・書き出しには含まれます）
- プロジェクトはJSON形式で保存／読み込みできます（音源ファイル自体はJSONに含まれないため、開くときに再選択を求められます）

## Windows版（インストーラー）

このリポジトリの Releases から `WaveForge.Setup.1.0.0.exe` をダウンロードして実行してください。

- トラック数の上限なし。長い曲や重い処理はこちらが向いています
- Web版とプロジェクト（JSON）をそのままやり取りできます
- 初回起動時に「Windows によって PC が保護されました」と表示された場合は、「詳細情報」→「実行」を押してください（個人制作のためコード署名がありません）
